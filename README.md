# 🏦 Conta Bancária - Encapsulamento em Java

Este projeto faz parte do meu portfólio de estudos em Java e POO (Programação Orientada a Objetos). O objetivo principal foi aplicar os conceitos de **encapsulamento**, garantindo a proteção dos dados sensíveis de uma conta bancária.

## 🎯 Objetivo do Exercício
Criar uma estrutura de classe que represente uma conta bancária com:
- Atributos privados para segurança dos dados (`numeroConta`, `saldo`).
- Atributo público para acesso direto (`titular`).
- Implementação de métodos **Getters** e **Setters** para manipulação segura das informações.

## 🛠️ Tecnologias Utilizadas
- **Java 17** (ou a versão que você estiver usando)
- **Paradigma de Orientação a Objetos**

## 📂 Estrutura do Código
O projeto é composto por duas classes principais:
1. `ContaBancaria.java`: Define o modelo da conta com modificadores de acesso.
2. `Main.java`: Instancia objetos, atribui valores e exibe os dados no console.
